Datenschutzhinweise – watch-control

watch-control ist ein privates Projekt von Jan Albert und wird ausschließlich für den eigenen Gebrauch betrieben. Es gibt keine weiteren Nutzerinnen oder Nutzer.

Welche Daten verarbeitet werden

  • Sprachaufnahmen von wenigen Sekunden, die der Betreiber selbst über seine Uhr auslöst.
  • Google Tasks des Betreibers: Titel der Listen und offenen Aufgaben (zum Zuordnen) sowie neu angelegte oder ergänzte Aufgaben.

Zweck und Weitergabe

Die Aufnahme wird zur Abschrift und Zuordnung an die Google Gemini API übermittelt; das Ergebnis wird über die Google Tasks API in die eigenen Listen eingetragen. Darüber hinaus werden keine Daten an Dritte weitergegeben, verkauft oder für Werbung genutzt.

Speicherung

Audiodateien werden nicht gespeichert. Auf dem eigenen Server des Betreibers wird ein kurzes Protokoll (Abschrift, Ergebnis, Bearbeitungszeit) zur Fehlersuche geführt. Der Zugriff auf Google Tasks lässt sich jederzeit unter myaccount.google.com/permissions widerrufen.

Nutzung von Google-Nutzerdaten

Die Nutzung von Daten, die über Google-APIs empfangen werden, entspricht der Google API Services User Data Policy, einschließlich der Anforderungen zur eingeschränkten Nutzung (Limited Use).
